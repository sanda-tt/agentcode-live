# C demo

Open this directory as a separate VS Code folder. Open **AgentCode Live** and enable **Follow Agent**. From the repository root run:

    node examples/play-demo.mjs

The demo writes only files prefixed with `agentcode_demo_` in this directory. The final file is a small C program. Rerunning resets the three files generated by the preceding run.

## C 示例

在 VS Code 中单独打开本目录，在命令面板运行「AgentCode Live: 实时观看代码变更」。从仓库根目录执行 `node examples/play-demo.mjs`。

脚本只会写入本目录中以 `agentcode_demo_` 开头的文件。最终保留一个小型 C 程序。再次运行会重置上一次演示生成的三个文件。
