# AgentCode Live for DeepSeek Harness

This Cordis bundle forwards native session and tool activity metadata to AgentCode Live in VS Code. It also contributes a live File activity tab to DSH Web sessions. It requires official DeepSeek Harness 0.2.2-rc.5. See [the installation guide](https://github.com/sanda-tt/agentcode-live/blob/main/docs/dsh.md).
